# Security policy

## Reporting a problem
Please report a security problem **privately**, not in a public issue:

1. Open the **Security** tab of this repository and choose **Report a vulnerability** (GitHub private vulnerability reporting).
2. Say what you found, the Wuber version, and the steps to see it. A short test or a log is enough.

Do not post the details in an issue, a pull request or a comment until the maintainer has answered.

## How fast we answer
The maintainer aims to answer a private report within 7 days and to publish a fix, or say why not, within 90 days. These are goals, not guarantees: Wuber is a hobby project kept by one person.

## What counts
Wuber is a client-side game addon with no server. Examples that count:
- a way to make Wuber send chat, cast, target or accept a trade without a real click;
- a way for another player's addon message to run code, change your saved settings or crash your game on purpose;
- a leak of personal data (account ids, paths, e-mail addresses) in a file of this repository or in a release.

Not a security problem: a wrong price, a missing driver, a layout fault. Open a normal issue for those.

## Versions
Only the newest release on CurseForge is supported.

## Thanks
Reporters who ask to be named are named in the release notes of the fix.
